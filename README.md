## Running locally

```bash
cp .env.example .env.local   # then fill in the keys
npm install
npm run dev                  # http://localhost:3000
```

Environment variables (see `.env.example`):

- `GOOGLE_GENERATIVE_AI_API_KEY` – Gemini key for the "Ask Binyam" assistant (`/api/persona`).
- `PERSONA_AI_MODEL` – optional model override.
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `CONTACT_TO` – the contact form emails you via `/api/contact` over SMTP (a Gmail app password works).

All profile content (bio, experience, projects, skills, credentials) lives in `lib/persona/knowledge.ts` and drives the UI, the OG image, the sitemap and the assistant's knowledge. Blog posts live in `lib/blog-data.ts`.
